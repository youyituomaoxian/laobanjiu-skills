# 报告风格与组件规范

本规范定义行业分析报告的视觉交付标准。**默认风格：弘讯暗色（preset A）**，备选 hot-analysis 深藏蓝紫（preset B）、shadcn Zinc 深灰（preset C）。除使用者明确要求，一律用默认风格。

> **令牌来源**：弘讯 B 端设计系统 `tokens.json` 顶层 `dark` 节 —— 由 `generatePalette('#005EAE',{mode:'dark'})` 引擎输出，是暗色的唯一真源。
> 本规范只做「设计系统令牌 → 报告 CSS 变量」的映射，**不改写、不自创令牌值**。若需换色，先改 tokens.json 再回到这里同步。

## 一、设计令牌（默认 · 弘讯暗色）

```css
:root{
  /* ── 表面层级（弘讯 dark.background / elevation；页面 < 卡片 < 浮层） ── */
  --bg:#121826;            /* background.page      · 深灰带品牌冷调（不是纯黑） */
  --surface:#1E293B;       /* background.surface    · 卡片面 */
  --surface2:#243044;      /* background.elevated   · 抬升面 / 表头 / tooltip */
  --sunken:#0F172A;        /* elevation.sunken      · 凹槽（代码块底） */
  --brand-surface:#0A2540; /* 品牌深表面 · 结构骨架（导航 / 页脚）专用 */
  --border:#334155;        /* background.border */
  --border-soft:rgba(51,65,85,.6); /* 表格行分隔 = border 降透明度（弘讯无独立弱边框令牌） */
  --text:#F1F5F9;          /* textPrimary */
  --text2:#CBD5E1;         /* textSecondary */
  --text3:#94A3B8;         /* textTertiary */
  /* ── 主色（弘讯 dark.colors.primary / secondary，暗色下提亮保对比） ── */
  --accent:#3B82F6;        /* primary */
  --accent-hover:#60A5FA;  /* primary.hover · 暗底小字用，保证对比度 ≥4.5:1 */
  --accent-active:#2563EB; /* primary.click */
  --accent2:#38BDF8;       /* secondary · 辅调青 */
  --link:#60A5FA;          /* link */
  /* ── 功能色（弘讯 dark.functional，Web 端值；移动端另有值，不可混用） ── */
  --green:#52C41A;  /* success */
  --red:#FF4D4F;    /* error   */
  --orange:#FFA940; /* warning */
  --yellow:#FFA940; /* 弘讯暗色无独立黄阶，黄色统一取 warning */
  --running:#22C55E;/* running（进行中 / 中性偏正） */
  /* ── 功能色柔底（弘讯 dark.functional.*.bg）——提示框底色 ── */
  --suc-soft:#162312; --warn-soft:#2E2410; --err-soft:#2A1414; --run-soft:#0E2018;
  /* ── 投影（弘讯 dark.shadow：暗阴影 + 白色发丝线） ── */
  --shadow-card:0 1px 2px rgba(0,0,0,.40), 0 0 0 1px rgba(255,255,255,.04);
  /* ── 圆角（只用弘讯 radius 阶：base 4 / md 8 / lg 16 / round 999） ── */
  --r-base:4px; --r-md:8px; --r-lg:16px;
  /* 中国金融市场惯例：红涨绿跌（与欧美相反） */
  --up:var(--red); --down:var(--green);
  --font-sans:'Roboto','Source Han Sans CN','思源黑体','PingFang SC','Microsoft YaHei',-apple-system,BlinkMacSystemFont,'Segoe UI',sans-serif;
  --font-mono:'JetBrains Mono','SF Mono',Consolas,'Liberation Mono',Menlo,monospace;
}
```

### 三条硬约束（违反就不像弘讯）

1. **结构骨架用 `--brand-surface`**。导航栏（报告的 chrome）底色必须是 `rgba(10,37,64,.88)` 品牌深蓝 + `backdrop-filter:blur(20px)`，边框 `rgba(96,165,250,.22)`。
   **为什么**：暗色下 `--accent` 提亮成 `#3B82F6`，若骨架仍用它作底，会出现「亮蓝壳 + 深色芯」的割裂感。改用 `#0A2540` 深蓝黑带品牌调，与内容区自然过渡。这是弘讯暗色最标志性的一条。
2. **表面层级不可倒置**。页面 `#121826` 最深 → 卡片 `#1E293B` 稍浅 → 抬升面 `#243044` 更浅。暗色不是亮色的机械反相，必须保住「页面 < 卡片 < 浮层」的明度顺序。
3. **投影 = 暗阴影 + 白色发丝线**，不用浅色光晕替代阴影（`--shadow-card`）。

### 几何与字体（一律取弘讯令牌阶，不自创）

## 二、十个标志性元素（决定「像不像」）

只换色值不会得到这套风格。以下 10 条元素缺一就会明显不像（1–9 为通用，10 为弘讯暗色专属）；**另有动效层（滚动显影 / 字符级显影），见「二·补」**：

1. **Hero 区（banner 底）** — `min-height:50vh` 居中布局 + **banner 背景**（品牌深表面 → 页面底纵向渐变 `linear-gradient(180deg,#0A2540,..,var(--bg))`，与导航栏同色系）+ 点阵纹理层 `.banner-deco`（辅调青 16% 点、26px 间距、向下渐隐）+ 两层 `radial-gradient` 光晕（`rgba(59,130,246,.12)` / `rgba(56,189,248,.07)`）+ 缓慢漂移动画（10s alternate，位移 ≤3%）；底边用品牌发丝线 `rgba(96,165,250,.22)` 与导航栏咬合
2. **渐变标题** — `linear-gradient(135deg,#F1F5F9,#60A5FA,#38BDF8)` + `-webkit-background-clip:text` + `-webkit-text-fill-color:transparent`
3. **编号章节徽章** — `36×36`、圆角 8px、底色 `rgba(59,130,246,.14)`、字色 `--accent-hover`、`line-height` 等于高度
4. **锚点导航** — `position:sticky;top:0` + 品牌深蓝毛玻璃 + 圆角 4px 胶囊链接（`padding:8px 16px`、`font-weight:600`），hover 填充 `--surface2`
5. **提示框体系** — 圆角 8px、**无左侧色条**；柔底取弘讯功能色 `*.bg`（见下表）
6. **摘要盒** — `linear-gradient(135deg,rgba(59,130,246,.10),rgba(56,189,248,.06))` + 边框 `rgba(59,130,246,.24)` + `✦` 项目符号
7. **表格** — 表头 `--surface2` 底 + 11px 大写字距 `letter-spacing:.05em` + 行 hover `rgba(59,130,246,.05)`
8. **回到顶部** — 右下角固定 `44×44`、圆角 8px、hover 时边框转 `--accent` 并加 `--shadow-card`
9. **等宽数字** — 所有数值用 `--font-mono` + `font-feature-settings:"tnum"` 保证表格纵向对齐
10. **品牌深表面骨架** — 导航与页脚 chrome 用 `--brand-surface` `#0A2540`，边框发丝线 `rgba(96,165,250,.22)`

**提示框柔底映射表**（左=类名，底=弘讯令牌，边框与标题取功能色低透明 / 原色）：

| 类名 | 语义 | 底色 | 标题色 |
|---|---|---|---|
| `.tip` | 信息 | `rgba(56,189,248,.10)`（secondary 降透明，弘讯暗色无 info 柔底令牌） | `--accent2` |
| `.warn` | 警告 | `--warn-soft` `#2E2410` | `--orange` |
| `.crit` | 严重 | `--err-soft` `#2A1414` | `--red` |
| `.ok` | 正常 | `--suc-soft` `#162312` | `--green` |

**动效强制要求**：必须带降级 ——

```css
@media (prefers-reduced-motion:reduce){
  *,*::before,*::after{animation-duration:0.01ms!important;animation-iteration-count:1!important}
}
```

## 二·补、动效层（原生实现）

参考稿（3D Creator portfolio）用 Framer Motion 实现的效果，在这里翻译成**零依赖原生实现**——报告仍是单个静态 HTML，不引入任何库：

| 效果 | 落点 | 原生实现 |
|---|---|---|
| **① FadeIn 滚动显影** | 各 `section` 的 h2 / `.lead` / h3 / `.tw` / `.chart-box` / `.callout` / `.risk`，以及 `.grid > *`、`.chain > .node`、`.tl > .tl-i` 子项 stagger（70/70/60ms） | `IntersectionObserver`（`rootMargin:0 0 -48px 0`，命中后 `unobserve`）+ CSS `transition` |
| **② AnimatedText 字符级显影** | 01 执行摘要 `.summary-box` 的 5 条结论 | 逐字切分 `<li>` 文本（递归下钻，保留 `<b>` / `<span class="b">` 行内结构），按元素在视口中的位置算进度，逐字 `opacity .2 → 1`（对应参考稿 offset `['start 0.8','end 0.2']`） |

> 参考稿里的 **Sticky Stack（卡片粘性堆叠）与 Marquee 已弃用**：前者会为 3 张卡吃掉 100vh+ 的滚动长度，把报告的纵向信息密度压垮；后者需要图片素材，报告无图。情景预测保持三栏并排。

### 硬约束（违反会导致内容不可读或门禁失败）

1. **统一开关 `html.js-anim`**。该 class 只在「浏览器支持 IntersectionObserver」且「未开启系统减弱动效」时由 JS 加上。所有动效样式必须写在 `html.js-anim` 选择器下，**不得写裸的 `opacity:0`** —— 否则无 JS 环境下内容直接消失。
2. **打印必须全量还原**。`@media print` 里把 `.reveal` 的 opacity / transform 与 `.ach` 的 opacity 强制还原。带 `!important` 的样式表声明能压过 JS 写入的内联样式，这是唯一可靠的办法 —— 用户没滚动过就导出 PDF 时，否则拿到的是空白章节。
3. **滚动监听必须 rAF 节流 + `passive:true`**。核心结论逐字显影会产生 200+ 个 span，不节流会拖垮滚动性能。
4. **拉丁 / 数字串整体不可断行**。逐字切分时把 `2026H1`、`+6.8%`、`>8%` 这类串整体包进 `.aw{white-space:nowrap}`，否则会在字符间断行。中文按字断行是正常的。

### 改回无动效版

删掉文件末尾那段「动效层」JS 即可 —— 样式全挂在 `html.js-anim` 下，没人加这个 class，一切自动回归静态。

## 四、图表规范

图表库：**Chart.js 4.x（cdnjs）**，颜色必须取自上述令牌，不得另起配色。

```js
Chart.defaults.color = '#94A3B8';                 /* textTertiary，不直接引 chart 色作文字 */
Chart.defaults.font.family = "'Roboto','Source Han Sans CN','思源黑体','PingFang SC','Microsoft YaHei',-apple-system,BlinkMacSystemFont,'Segoe UI',sans-serif";
Chart.defaults.borderColor = '#3E4C63';           /* chartGrid */
const UP='#FF4D4F', DOWN='#52C41A',               /* 弘讯 error / success · 红涨绿跌 */
      BLUE='#38BDF8', CYAN='#00C7BE', PURPLE='#8A5CF5',
      ORANGE='#FF9500', YELLOW='#FFA940', MUTE='#94A3B8';
/* 说明：BLUE=secondary；CYAN=dataCyan；PURPLE=wisdomPurple；ORANGE=vividOrange；
   YELLOW=warning；MUTE=中性 N8（textTertiary），用于历史段 / 基准线 */
const GRID = {color:'#3E4C63', drawBorder:false};               /* dark.colors.chartGrid */
const TT = {backgroundColor:'#243044', borderColor:'#334155', borderWidth:1,
            titleColor:'#F1F5F9', bodyColor:'#CBD5E1', padding:10, cornerRadius:8};
```

**弘讯图表 8 色扩展板**（多系列时按序取用，与亮度色共用）：

`techBlue #0066CC` · `smartCyan #00A3E0` · `dataCyan #00C7BE` · `freshGreen #00D4A1` · `vividOrange #FF9500` · `alertRed #FF4D4D` · `wisdomPurple #8A5CF5` · `modernPink #FF66C2`

> ⚠️ **暗底禁用**：`techBlue #0066CC` 在 `#121826` 上对比 <3:1，**禁作主系列线 / 描边**（可作大面积填充或亮系替换）。移动端另有 `blue-aux #1D4ED8`、`green-growth #059669` 同属禁用。

### 硬规则

- **红涨绿跌**：所有表示增长/上涨的用 `--up`（红 `#FF4D4F`），下降用 `--down`（绿 `#52C41A`）。面向国际读者时整体反转。
- **同一含义全文同色**：收入永远一个颜色，下载量永远一个颜色，不得在两张图里互换。
- **轴必须标单位**：`y:{title:{display:true,text:'亿美元'}}`。
- **基线有争议的年份留空不画**，并在 tooltip 或脚注写明留空原因。
- **示意性图形必须标注**「量级示意，非精算」（如多项占比简单加总）。
- **图表最小必要原则**：每张图必须回答一个非它不可的问题。自查话术——「这张图删掉，读者会损失哪个判断？」答不出来就删。
  - 同一数据的柱状图与折线图不得并存
  - 饼图/环形图仅用于构成比且类别 ≤6，超过 6 类改横向条形图
  - 双轴图先确认两轴数据量级差异能自证，否则拆成两张
- 暗色图表所有网格线用 `#3E4C63`（chartGrid），不得用纯白或高对比灰。
- **文字走 N 级文字令牌**（`--text3` / `--text2`），环状图底环用 `--surface2`，不直接引 chart 色作文字。

### 建议图表组合

规模趋势（柱+折线双轴）｜区域或构成（环形）｜竞争份额（横向条形）｜集中度趋势（折线）｜五力（雷达）｜成本对比（条形）｜三情景路径（多线，历史段用 MUTE 灰区分）

## 五、可打印为 PDF

- 页面在 `@media print` 下保持深色需用户开启「背景图形」
- 报告尾注中提示这一点
- 避免使用 `position:fixed` 元素遮挡内容（`.btt` 需在打印时隐藏）

## 六、响应式与可访问性

- 断点 `900px`（网格转单列）与 `640px`（导航缩字、章节标题降级）
- 数值与正文对比度 ≥ 4.5:1；`--text3` 仅用于辅助信息，不承载关键数字
- `--accent` `#3B82F6` 在 `--bg` 上对比约 4.4:1 → 承载正文级文字时改用 `--accent-hover` `#60A5FA`（≈5.9:1）
- 表格外层必须 `overflow-x:auto`，避免小屏溢出
- `h2` 的编号徽章为装饰元素，不承担语义（不放进 `<h2>` 文本内会破坏大纲时，改用 `aria-label` 说明章节序号）
