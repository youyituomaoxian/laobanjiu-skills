# 报告风格与组件规范

本规范定义行业分析报告的视觉交付标准。**默认风格：hot-analysis 深藏蓝紫**（预设 A），备选 shadcn Zinc 深灰（预设 B）。两套令牌并列，除非使用者明确要求，一律用预设 A。

---

## 一、设计令牌（预设 A · hot-analysis 深藏蓝紫）

```css
:root{
  --bg:#0b0f19;        /* 页面底 · 深藏蓝 */
  --surface:#131a2b;   /* 卡片面 */
  --surface2:#1a2339;  /* 次级面 · 表头 / 代码块底 */
  --border:#1e2d4a;    /* 边框 */
  --border-soft:#16203a;/* 更弱的分隔线（表格行） */
  --text:#e2e8f0;      /* 主文字 */
  --text2:#94a3b8;     /* 次要文字 · 正文 */
  --text3:#64748b;     /* 三级文字 · 提示 / 表头 */
  --accent:#a78bfa;    /* 主调 · 紫 */
  --accent2:#38bdf8;   /* 辅调 · 天蓝 */
  --green:#34d399; --red:#f87171; --orange:#fb923c; --yellow:#fbbf24;
  /* 中国金融市场惯例：红涨绿跌（与欧美相反） */
  --up:var(--red); --down:var(--green);
  --font-sans:'Inter',-apple-system,BlinkMacSystemFont,'Segoe UI','PingFang SC','Microsoft YaHei',sans-serif;
  --font-mono:'JetBrains Mono','Cascadia Code','Fira Code',Consolas,monospace;
}
```

**导航栏毛玻璃底**必须与 `--bg` 同色系：`rgba(11,15,25,0.85)` + `backdrop-filter:blur(20px)`。

## 二、九个标志性元素（决定「像不像」）

只换色值不会得到这套风格。以下元素缺一就会明显不像：

1. **Hero 区** — `min-height:50vh` 居中布局 + 两层 `radial-gradient` 光晕（accent 10% / accent2 6%）+ 缓慢漂移动画（10s alternate，位移 ≤3%）
2. **渐变标题** — `linear-gradient(135deg,#e2e8f0,#a78bfa,#38bdf8)` + `-webkit-background-clip:text` + `-webkit-text-fill-color:transparent`
3. **编号章节徽章** — `36×36`、圆角 8px、底色 `rgba(167,139,250,.12)`、字色 accent、`line-height` 等于高度
4. **锚点导航** — `position:sticky;top:0` + 毛玻璃 + 圆角 6px 胶囊链接（`padding:8px 16px`、`font-weight:600`），hover 填充 `--surface2`
5. **提示框体系** — `.tip`（天蓝 6% 底 + 15% 边框）/ `.warn`（红 6% 底 + 15% 边框），**圆角 8px、无左侧色条**
6. **摘要盒** — `linear-gradient(135deg, rgba(167,139,250,.08), rgba(56,189,248,.06))` + 边框 `rgba(167,139,250,.2)` + `✦` 项目符号
7. **表格** — 表头 `--surface2` 底 + 11px 大写字距 `letter-spacing:.05em` + 行 hover 时 `rgba(167,139,250,.03)`
8. **回到顶部** — 右下角固定 `44×44`、圆角 12px、hover 时边框转 accent
9. **等宽数字** — 所有数值用 `--font-mono` + `font-feature-settings:"tnum"` 保证表格纵向对齐

**动效强制要求**：必须带降级 ——

```css
@media (prefers-reduced-motion:reduce){
  *,*::before,*::after{animation-duration:0.01ms!important;animation-iteration-count:1!important}
}
```

## 四、图表规范

图表库：**Chart.js 4.x（cdnjs）**，颜色必须取自上述令牌，不得另起配色。

```js
Chart.defaults.color = '#94a3b8';
Chart.defaults.font.family = "'Inter',-apple-system,BlinkMacSystemFont,'Segoe UI','PingFang SC','Microsoft YaHei',sans-serif";
const UP='#f87171', DOWN='#34d399', BLUE='#38bdf8', CYAN='#a78bfa', PURPLE='#a78bfa',
      ORANGE='#fb923c', YELLOW='#fbbf24', MUTE='#64748b';
const grid = {color:'#16203a', drawBorder:false};
const tt = {backgroundColor:'#131a2b', borderColor:'#1e2d4a', borderWidth:1,
            titleColor:'#e2e8f0', bodyColor:'#94a3b8', padding:10, cornerRadius:8};
```

### 硬规则

- **红涨绿跌**：所有表示增长/上涨的用 `--up`（红），下降用 `--down`（绿）。面向国际读者时整体反转。
- **同一含义全文同色**：收入永远一个颜色，下载量永远一个颜色，不得在两张图里互换。
- **轴必须标单位**：`y:{title:{display:true,text:'亿美元'}}`。
- **基线有争议的年份留空不画**，并在 tooltip 或脚注写明留空原因。
- **示意性图形必须标注**「量级示意，非精算」（如多项占比简单加总）。
- **图表最小必要原则**：每张图必须回答一个非它不可的问题。自查话术——「这张图删掉，读者会损失哪个判断？」答不出来就删。
  - 同一数据的柱状图与折线图不得并存
  - 饼图/环形图仅用于构成比且类别 ≤6，超过 6 类改横向条形图
  - 双轴图先确认两轴数据量级差异能自证，否则拆成两张
- 暗色图表所有网格线用 `#16203a`，不得用纯白或高对比灰。

### 建议图表组合

规模趋势（柱+折线双轴）｜区域或构成（环形）｜竞争份额（横向条形）｜集中度趋势（折线）｜五力（雷达）｜成本对比（条形）｜三情景路径（多线，历史段用 MUTE 灰区分）

## 五、可打印为 PDF

- 页面在 `@media print` 下保持深色需用户开启「背景图形」
- 报告尾注中提示这一点
- 避免使用 `position:fixed` 元素遮挡内容（`.btt` 需在打印时隐藏）

## 六、响应式与可访问性

- 断点 `900px`（网格转单列）与 `640px`（导航缩字、章节标题降级）
- 数值与正文对比度 ≥ 4.5:1；`--text3` 仅用于辅助信息，不承载关键数字
- 表格外层必须 `overflow-x:auto`，避免小屏溢出
- `h2` 的编号徽章为装饰元素，不承担语义（不放进 `<h2>` 文本内会破坏大纲时，改用 `aria-label` 说明章节序号）
